## What is Forma?

Forma is an interactive theorem proving system. Designed to make it easy for you to feel ready to advance your skills and go beyond pen-and-paper proofs. Start off on the right foot with proof assistants.

A live version is available at [zarkino.github.io/Forma](https://zarkino.github.io/Forma/).

![Chrome Dark](https://github.com/Zarkino/Forma/assets/31597902/1f7acbe6-e5e4-4dcb-9f63-8bcbf2d065de)

## Getting Started

To clone and run this application, you will need [Git](https://git-scm.com/downloads), the [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) and [Node.js](https://nodejs.org/en/download) version 18 or higher installed on your computer.

From your command line:

```bash
# Clone this repository
git clone https://github.com/Zarkino/Forma.git

# Go into the repository
cd Forma

# Install dependencies
npm install

# Run the application
npm start
```

The web application will be accessible at [http://localhost:5173](http://localhost:5173).

## Other commands

```bash
# Run the test suite
npm test

# Build a static site into dist/
npm run build

# Build the whole application as a single self-contained HTML file
npm run build-single-file
```
